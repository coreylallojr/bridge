BRIDGE

      
One-click tiles, a Start my day routine that lays your apps out across your monitors, live widgets,
        and an arc reactor at the center. A JARVIS-style HUD, built with Tauri 2 and Rust. Local only.

Capabilities
v0.3.0

    
    
      
  • 
        
    Tiles
    One-click links, apps, folders and scripts, grouped and searchable from a command palette.
    • 
      
  • 
        
    Start my day
    Opens your apps and places their windows on your monitors, with zones and workspaces. Later runs reuse open windows.
    • 
      
  • 
        
    Widgets and themes
    Live widgets for your routine, recent launches and PC stats, plus themes, density, font scale, motion and quality controls.
    • 
      
  • 
        
    Arc reactor
    An animated reactor centerpiece with the clock at its core. Calm motion gives a still glow.
    • 
      
  • 
        
    Shell
    A global hotkey (default Alt+Space), tray icon, single instance, and a bridge … CLI over a named pipe.
    • 
      
  • 
        
    Local only
    No cloud services and no telemetry. Fonts and Three.js are bundled; your profile stays on your machine.
    • 
    

  


  
  

    
Build it
Windows 10 / 11

    
Requirements: Windows 10 or 11 with WebView2, Node 20+, and Rust (stable). Both the GNU and MSVC toolchains work.

    

      
PowerShell

      
git clone https://github.com/coreylallojr/bridge && cd bridge

      
npm install

      
npm run tauri:build# vite build + release exe (the first build is slow)

      
npm start# run it

    

    
On first run Bridge seeds %APPDATA%\Bridge\profile.json from examples/starter-profile.json.
      Edit tiles in the app or in that file. Tests: npm test, npm run rust:test, npm run typecheck.
